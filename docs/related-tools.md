# Related tools

Codestrand is inspired by [Gource][gource]; other Git history visualisers and
Gource helpers offer several ways to explore a repository.

## Gource and helpers

| Tool | View or role | Built with | Runs as |
| --- | --- | --- | --- |
| [Gource][gource] | File trees and contributors | OpenGL | Desktop; frame output |
| [Rource (AdamLeyshon)][logs] | Multi-repo logs and aliases | Rust | CLI for Gource |
| [gourcers][gourcers] | Clone repos and merge logs | Rust | CLI for Gource |
| [Envisaged][envisaged] | Git history videos | Python, Gource, FFmpeg | CLI; web UI |
| [Envisaged Redux][redux] | Git history videos | Gource, FFmpeg | Docker; web preview |

## Gource-style trees

| Tool | View | Built with | Runs as |
| --- | --- | --- | --- |
| [Gource View][view] | Trees and contributors | Node.js server | Browser; MP4 export |
| [Rource (kauandotnet)][rource] | Animated trees | Rust, WASM | Desktop; browser |

## Cities, networks and treemaps

| Tool | View | Built with | Runs as |
| --- | --- | --- | --- |
| [Sourcity][sourcity] | Voxel cities and robots | .NET, Raylib-cs | Desktop |
| [Git City][city] | City and farm history replay | Electron | Desktop Git client |
| [Repo Visualizer][network] | Import networks | Canvas, WebGL | Browser; video |
| [strata][strata] | Treemaps, trees and charts | Rust, TypeScript/D3 | Browser; video |
| [gitatlas][atlas] | Animated file treemaps | Rust, FFmpeg | CLI video renderer |
